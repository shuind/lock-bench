# 缺页压力四种接入对照

64 MiB 内存与 memsw 限额，256 MiB 固定文件映射与 16 MiB 匿名内存；4 线程扫描 15 遍。比较 fentry、kprobe、普通/raw tracepoint，均仅计数和配对。

## 测量范围

扫描程序在独立 cgroup v1 中，内存和内存＋swap 限额均为 64 MiB，swappiness=0。扫描前建立 256 MiB 文件只读共享映射，另触碰并保留 16 MiB 匿名内存。

4 个线程各负责四分之一映射，正式扫描 15 遍，每页只读开头的 8 字节数字并累计校验。4 KiB 页面共 65,536 个，合计 983,040 次页面访问；这不是缺页次数或锁次数。正式窗口没有反复 mmap/munmap；映射关系保持，页面驻留、页表项、回收和 refault 会变化。

准备文件、映射、预热、创建线程、加载/卸载探针、最终导出均在扫描计时外。实际缺页、回收、I/O 等工作不会因为固定访问量就完全相同，需结合原始压力指标和系统起止快照判断波动。

四种接入各做三组配对。主 CPU 合计扫描与控制程序，独立观测程序另列。

## 结果

每方式 3 组，共 12 组成对比较；属于探索性对照。
